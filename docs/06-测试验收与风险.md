# 测试验收与风险

状态：未来验收方案。本次只检查研究证据与文档一致性，没有运行应用测试或连接手表。

## 1. 测试层级与设备

| 层级 | 覆盖重点 | 依据/限制 |
| --- | --- | --- |
| 纯逻辑单测 | 队列模式、乱序/重复命令、歌词边界、二维码状态、资源错误映射、任务恢复 | 使用脱敏固定样本；不在 CI 放真实 Cookie |
| 网络契约 | 请求构造、分页、登录失效、限流、空 URL、试听、下载权限 | mock + 开发阶段受控真实接口；mock 不能证明线上可用 |
| 设备集成 | MediaController/Service、焦点、通知、数据库、本地来源授权与扫描、下载缓存 | 使用云端生成的应用和测试 APK；本地执行设备验证，不编译 |
| UI | 小宽度、圆屏、大字体、状态、返回、分页 | 截图和操作记录；矩形模拟器不能代替圆表 |
| 长时实测 | 熄屏、蓝牙、网络切换、回收、耗电与发热 | Watch X2 为主要门槛 |

主设备固定为用户的 OPPO Watch X2；记录具体系统/固件、API 和 ABI。补充一个无 GMS 的普通 Android 测试环境验证无硬依赖。未来 P7 至少加入一个实际支持的 Wear OS 环境；商店要求与厂商后台行为需要相应设备/渠道重新验证。

## 2. 关键测试用例

| ID | 用例 | 通过条件 |
| --- | --- | --- |
| T-01 | 安装、启动器、升级安装 | 正确显示入口；数据按预期保留；签名/包名独立；不能依赖 root |
| T-02 | 无 GMS 启动 | 登录前/后核心路径无缺失服务崩溃 |
| T-03 | QR 成功、过期、网络失败、取消 | 状态正确，退出后无轮询，新 QR 不受旧回调覆盖 |
| T-04 | 登录持久化/密钥失效/账号切换 | 无明文回退；重登可恢复；旧账号请求不能写入新账号列表 |
| T-05 | 1000 首歌单及搜索多页 | 分批加载，去重，顺序稳定，能到末页，不一次展开全部对象 |
| T-06 | 资源不可播、试听、权益不足、URL 过期 | 明确显示不可播放或实际可用质量；重试有上限；不把试听当完整歌曲 |
| T-07 | 快速连续点歌/暂停/seek | 最后一次意图生效；无旧曲抢播、无重复播放器 |

| T-09 | 蓝牙断开/重连和耳机媒体键 | 断开暂停；不自动外放；媒体键命令可靠到达服务 |
| T-10 | 来电、语音助手、其他媒体抢焦点 | 按焦点类型暂停/降音；恢复政策一致；不与其他应用持续抢占 |
| T-11 | 网络断开、Wi-Fi 切换、弱网、429/超时 | 缓冲/失败可见，退避有上限，已下载曲目仍可播放 |
| T-12 | UI 进程/Activity 重建及普通进程回收 | 队列、位置和页面恢复；不把 onDestroy 当唯一保存时机 |
| T-13 | 用户强制停止及设备重启 | 不承诺强停后继续；再次打开可恢复记录，默认暂停 |
| T-14 | 无歌词、纯音乐、乱序时间戳、seek、切歌 | 播放不受解析异常影响；歌词不串歌；手动浏览能返回当前行 |
| T-15 | 下载中断、暂停、杀进程、恢复 | 任务可恢复或明确失败；Completed 与完整资源一致 |
| T-16 | 下载 URL 续期、Range 不支持/内容改变 | 不拼接不同资源；可重启下载；错误可诊断 |
| T-17 | 飞行/断网纯离线启动和播放 | 已下载音乐出声；不强制校验短期播放 URL；缺失歌词不影响音频 |
| T-18 | 低空间、清缓存、删除下载、重复下载 | 空间边界明确；清缓存不删下载；索引和文件一致 |
| T-19 | 圆屏/大字体/长标题/二维码/表冠 | 核心按钮无裁切；二维码可扫描；表冠不可用时触控完成全部任务 |
| T-20 | 日志和导出 | 无 Cookie、key、完整签名资源地址或隐私响应；导出不自动发送 |
| T-21 | 低电、省电/厂商特殊模式 | 记录允许的播放模式及系统限制；不以后台轮询或无限唤醒绕过限制 |
| T-22 | LAN / Wear OS（可选阶段） | 不影响独立模式；目标设备明确；不支持时正常降级 |
| T-23 | 无账号、无互联网本地启动与播放 | 无全屏登录拦截；本地库、搜索、播放、队列和本地 LRC 可用，不以线上解析或登录校验为前置 |
| T-24 | 本地授权/拒绝/撤销/重新授权 | 拒绝不崩溃；撤销标记不可达且保留索引/歌单；重新授权后可恢复，不要求 root 或所有文件访问权限 |
| T-25 | 首扫、增量扫、取消、目录异常 | 显示进度和失败项；部分扫描失败不把未扫描文件当已删除；增删改准确协调，重复扫描不重复建库 |
| T-26 | 1000 首本地库、分类、搜索和排序 | 真分页；歌曲/专辑/歌手/文件夹分类正确；未知标签可回退文件名；首屏不等全库读完 |
| T-27 | 本地收藏与歌单 | 创建、重命名、删除歌单、增删曲目与调整顺序重启后保持；不修改在线歌单，不删除外部原文件 |
| T-28 | 文件丢失/移动/坏文件/格式不支持 | 明确错误和恢复路径；不误播其他文件、不无限跳过；恢复索引不凭相同标题合并不同副本 |
| T-29 | 本地封面与 LRC | 首声不等封面/歌词；同名匹配及编码失败有结果；大图与异常文本不拖慢播放；默认不联网补全 |
| T-30 | 扫描并行播放与熄屏 | 全局有界扫描；满足 14 的交互/内存预算；无账号无互联网本地熄屏连续 120 分钟 |
| T-31 | 本地文件、在线下载、缓存所有权 | 清缓存、退出账号、移除来源不误删原始文件/本地收藏；应用内显式导入副本与原始文件分别管理 |

## 3. 性能预算与测量方法

**性能第一，界面美观第二，可读性必须达标。** 性能预算、样本数、指标定义和回归判定已统一迁到 [14 性能优先与资源预算](14-性能优先与资源预算.md)，不在本文件复制另一套阈值。所有数字目前仍是目标，未完成实测。

P0/P1 建基线，P2（含 P2-L）/P3 持续回归，首版同时验证在线与本地；P5 是进一步收敛，不是开始优化的阶段。Debug 行为验证不代替优化候选测量；云端构建，真实 Watch X2 运行与采集。使用 [性能验收记录](templates/性能验收记录.md)，绑定实际 APK、source/build SHA、固件、样本和测量工具。未测不填 0，不把内部播放器事件当成真实首声，不用平均 FPS 掩盖长帧。

界面按 [15 视觉验收](15-界面设计与视觉验收.md) 和 [界面记录](templates/界面验收记录.md) 检查页面状态、实际圆形边界、大字体与无障碍。代码按 [16 可读性规范](16-代码规范与可读性.md) 审查命名、职责、注释和线程/取消约束；三者都要通过，截图漂亮不能抵消性能失败。

## 4. 风险清单

| 风险 | 概率/影响（规划判断） | 最早验证 | 应对及决策 |
| --- | --- | --- | --- |
| 目标系统限制侧载/启动入口 | 中 / 阻断 | P0 | 确认实际安装渠道；不假定所有 Watch X2 固件相同 |
| OEM 熄屏或低电模式终止服务 | 高 / 阻断核心体验 | P0 | 标准媒体前台服务实测；记录可用设置和不支持模式；失败则调整产品定位 |
| 原生二维码登录被限制 | 高 / 阻断在线登录 | P0 | 比较原生与可用 WebView 路线；两者失败则重新估算手机辅助方案 |
| 依赖工具链不匹配 | 中 / 高 | P0–P1 | 不照搬上游版本；冻结可构建组合；逐项验证最低 API |
| 上游核心与手机 UI 耦合 | 高 / 中高 | P1 | 最小依赖提取、窄接口；不从 watch 模块直接依赖手机 app |
| 搜索/歌单分页不完整 | 已发现上游 adapter 限制 / 中 | P2 | 验证第二页和末页，不能只测首页 |
| 音频资源失效/格式不支持 | 高 / 高 | P2 | 短期 URL 重新解析、标准音质、明确错误；不要静默选择不匹配曲目 |
| CPU/GPU/持续联网耗电 | 中高 / 高 | P1–P5 | 单播放器、关闭后台 UI 计时、低下载并发、停止非必要发现和轮询 |
| 下载半完成或内容串接 | 中 / 高 | P4 | 稳定 key、索引协调、完整性验证、URL 刷新时检查资源身份 |
| 手机蓝牙连接但无互联网/LAN | 中 / 中 | P0/P6 | 实测连通性；不把系统连接状态当可达性证据 |
| 不同地区版本误判为同一系统 | 中 / 高 | P0/P7 | 记录 SKU/固件/API，普通安卓与 Wear OS 分开验收 |
| 上游独立资源许可未处理 | 已有独立说明 / 中高 | P1/P5 | 默认不搬字体/PV 模板；记录实际复用文件和发布材料 |
| 本地来源不可访问或固件无文件选择器 | 中 / 阻断本地接入 | P0 / DEV-005 | 实测 MediaStore/SAF 与权限；选择受支持路径，不承诺所有固件均有目录选择器 |
| 本地整库扫描/封面解码争抢播放资源 | 高 / 高 | P2-L | 增量数据库、真实分页、全局低并发、按需封面；扫描中仍验证交互和音频 |
| 部分扫描失败造成误删索引/歌单引用 | 中 / 高 | P2-L | 区分不可达与已删除；成功扫描代次才做差量收敛；撤销权限后保留记录 |

## 5. 发布候选退出门槛

1. Watch X2 上版本范围内全部 FR 与本地音乐验收通过，失败场景有明确反馈；首版包含 P2-L、本地/缓存管理部分 FR-11；下载专属 FR-09–10 和 FR-11 的下载管理部分在 P4/P5 验收。
2. 无已知阻断崩溃、凭证泄漏、队列错乱或已完成下载被误删问题。
3. 按 14 完成首版在线 60 分钟与本地文件 120 分钟熄屏测试，P4 追加在线下载文件离线回归；明确固件、模式和必要设置，不泛称“所有安卓手表兼容”。
4. 性能、耗电、视觉和代码可读性有可复查记录；预算未达标先修复或由所有者基于证据明确调整，不静默放宽。
5. 存储、会话和下载索引的版本升级可回归；签名和包名保持自身版本连续。
6. 提供安装说明、独立签名构建方法、来源记录、许可材料和已知限制。

首版 MVP 包含在线与本地文件播放，可在无账号无互联网环境使用本地库；这不代表在线歌曲持久下载已完成，不能标记为完整 1.0。可选 LAN/Wear OS 阶段单独出具验收报告。
