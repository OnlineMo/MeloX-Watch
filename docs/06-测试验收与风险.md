# 测试验收与风险

状态：未来验收方案，终审2026-11-11。本次只编辑并检查文档，没有运行应用测试或连接手表。产品面向无GMS硬依赖的普通Android智能手表；Watch X2只是当前可用主测设备。

## 1. 范围与测试层级

[21 全量需求整合](21-本地播放器全量需求整合.md) 是当前范围决定；[匿名原文](requirements/local-player-F001-F128.md) 固定每项全部行为，[覆盖矩阵](requirements/local-player-coverage.json) 固定F、LP及AC编号，来源哈希见 [source记录](requirements/local-player-source.json)。**F-001–F-128全部必做，包括原13项范围待定；AC-001-N/E至AC-128-N/E共256项必须逐项记录正常/异常结果。** T用例是共用与组合回归，不替代或合并掉任何原AC。

验收分范围确认、参数决定、实现、云端验证、设备正常路径、设备异常路径及发布批准。当前只有规划；每个AC初始为未执行，参数尚未确定时列负责LP、待选内容、验证材料及退出条件。设备不支持可记录该组合的异常路径，不得把全功能只实现禁用状态当完成；每项必须至少在声明支持的设备/后端/授权方式/真实配套端或兼容接收端上通过正常路径。不能对强制AC整体标不适用。

完整公开版本验收覆盖所有LP-00–15。主测真表完成其支持的正常路径和默认/最大字体核心路径；其缺少的硬件/提供方/接收端能力由补充受支持配置留真实证据，并记录主测限制。只测模拟器、返回200、保存设置或出现按钮均不足以证明实际功能。普通设备不必同时具备所有格式、后端DSP组合或选择器，但项目层面的128项缺一仍未通过。

### 原AC结果记录要求

结果表每行标F-ID、主责LP、AC编号、原文契约引用、支持配置、夹具/输入、操作与实际副作用、结果、证据及未决项；256个原AC逐项判定。一次证据可关联多个AC，但每个AC均须证明自己的断言。正常证据不足保持未测/阻断，异常测试成功不能替代正常AC；不支持组合只在组合层注明理由。导出/删除/编辑等需看实际文件/数据库/对端结果，不能只截提示。

候选验收绑定同一冻结source/snapshot的手表＋手机APK组合；每包单独记录build SHA、run/attempt/artifact、包名、versionName/versionCode、APK与证书SHA-256，不能假定两包身份或证书相同。每个AC标候选组合ID、两端固件/API/ABI、后端/格式/路由、协议/schema及实际授权；F-084另记接收端身份和协议。更换任一包或组合需评审并重验受影响AC，不能只凭手表APK验收放行手机功能；最终逐包发布原已验字节。字段见 [本地验证记录](templates/本地验证记录.md) 和 [候选发布验收记录](templates/候选发布验收记录.md)。

## 3. 性能预算与测量方法

**性能第一，界面美观第二，可读性必须达标。** 性能预算、样本数、指标定义和回归判定已统一迁到 [14 性能优先与资源预算](14-性能优先与资源预算.md)，不在本文件复制另一套阈值。所有数字目前仍是目标，未完成实测。

P0先按14冻结主测设备的方法、初始目标及耗电可测性/替代标准，P1起回归；新增设备另建基线。保持180MiB等初始目标，不在验收失败后临时降低。耗电比例不可测时只判已冻结替代标准，不能宣称20%通过；应用ANR必须为零、无已知泄漏。

云端构建、设备运行。发行候选为优化Release、debuggable/profileable均false；诊断包独立哈希和差异说明，Debug或诊断结果不能冒充实际发行APK。使用 [性能验收记录](templates/性能验收记录.md)，保留原始样本/失败数，首声、暂停/已缓冲seek、总元数据解析分别按14；未知不填0，内部事件不等同实际出声。

每个PR只复核受影响用例；共享接口、数据或生命周期改变扩展到对应共同路径，首版完整验收不省略适用场景。界面按 [15 视觉验收](15-界面设计与视觉验收.md) 和 [界面记录](templates/界面验收记录.md) 检查页面状态、实际圆/方窗口边界、大字体与无障碍。代码按 [16 可读性规范](16-代码规范与可读性.md) 审查命名、职责、注释和线程/取消约束；三者都要通过，截图漂亮不能抵消性能失败。

## 5. 发布候选退出门槛

1. 首个完整公开版本全部128项及256原AC通过，保留在线/Meting与既有FR门槛。当前主测真表完成其支持的正常路径，缺失硬件/后端/提供方组合明确受限并补兼容配置证据；圆/方窗口代表布局、真实手机客户端和F-084接收端有记录。不冒称全设备/全格式/全后端兼容，不以整体禁用免除必做项。下载专属FR-09–10及FR-11下载部分仍按P4/P5验收。
2. 无已知阻断崩溃、ANR、资源泄漏、凭证泄漏、队列错乱或音频/本地整理数据被误删问题。

4. 性能/耗电按14在P0冻结的适用标准、视觉/可读性均有证据；失败先修复，后续预算变更需设备证据与所有者明确决定，不临时放宽或用未测值放行。
5. 初始建库及后续非破坏性迁移、授权/密钥失效和队列恢复按T-38–40验证；有升级版本时才声明升级通过，签名/包名连续。
6. 提供安装说明、独立签名构建方法、来源记录、许可材料和已知限制。
