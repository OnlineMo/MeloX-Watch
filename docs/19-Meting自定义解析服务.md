# Meting 自定义解析服务

状态：配置、协议适配、共享播放解析与设置页面源码已接入工程，尚未完成新增依赖准入、云端应用验证及设备验收，未请求实际用户音乐服务。**服务地址由用户填写，支持自建，不内置、推荐或自动回退到公共 API。** 本文件描述本次明确要求的 Meting 兼容适配；其他未来音源仍遵循 [18 通用接口预留](18-通用音源接口预留.md)，不提前指定平台或接入方式。

Meting 接入用于尝试取得服务能够提供的网易云歌曲资源，不承诺“所有歌曲解锁”。返回空、试听、权限错误、不可访问或受保护资源时如实呈现，不能将短音频伪装为完整版。实际能力由用户配置的服务及响应决定，不以 API 名称代替验证。

## 1. 在应用中的位置

网易云仍提供既有登录、喜欢、歌单、搜索和曲目身份；Meting 是用户选择的**可选播放解析服务**，其可配置能力属于首版必交范围。`TrackKey(providerId, trackId)` 保留原始身份，另记 `resolverId`、配置代次、资源来源声明及验证状态；来源未知就记录未知，不能把“请求网易云 ID”当作资源已经平台验证。

本地文件直接按本地 URI/授权处理，不访问 Meting，不被在线账号、网络或服务开关影响。媒体会话和活动后端仍各一个，页面不直接拼接 API 请求。当前直连解析和 Meting 适配位于同一 `PlaybackResolver` 的可替换解析步骤；未来有真实需求再新增实现，不能把此服务当作所有未来音源必须使用的协议。

## 2. 用户设置与自建服务

| --- | --- |
| 使用自定义解析服务 | 默认关闭；必须由用户填写有效地址并主动启用；空配置不会产生网络请求 |
| API 地址 | 支持完整 endpoint 或受限 URL 模板；保留用户自建路径和必需参数，不硬编码任何公网域名 |
| 模板模式 | 初始仅支持 `:server`、`:type`、`:id`，仅可出现在 URI 查询参数值中，替换值逐项编码；禁止放入 scheme/host/port/path/参数名。未知占位符保存时报错，不执行脚本 |
| 额外鉴权 | 仅当服务需要时配置该服务自己的凭据；加密保存，不使用用户的网易云 Cookie 或服务端签名主密钥代填 |
| 测试 | 使用当前网易云曲目或用户明确填写的测试曲目 ID 请求；无曲目时提示需要 ID。分别报告地址有效、协议兼容、资源解析及实际播放结果，不能只凭 HTTP 200 宣称可播放 |
| 启用后的策略 | 正常网易云路径优先；仅第4节允许的同 ID 空资源/试听/不可用结果可在剩余预算内尝试一次；显式重试开新操作，不循环切源 |
| 更改/关闭/删除 | 增加配置代次，取消待解析请求、废弃旧缓存并停止后续使用；已打开的当前音频流可继续，除非用户明确停止。需要新解析/重连时遵从新配置；不向新地址沿用旧凭据，不删除曲目或本地数据 |

### 2.1 传输和凭据策略

HTTPS 默认开启且正常校验证书/主机名，不提供 TLS 绕过。HTTP 需用户为服务明确开启，仅允许配置的精确 origin（scheme、规范化 host、有效 port）；HTTP 媒体/封面/LRC 也只能回该 origin，其他主机只接受 HTTPS。不得从 HTTPS 静默降到 HTTP；服务 URL 拒绝 userinfo 和非 HTTP(S) scheme，本地 URI 只来自已授权本地路径。

Android 网络安全 XML 随 APK 静态打包，不能在运行时加入用户任意域名。实现用独立服务客户端和一个小型共享传输检查函数：每次实际请求（含媒体、图片、歌词与后续下载）在发出前核对协议、解析配置及 origin，只有当前明确允许的服务上下文可发 HTTP。若支持任意自填 HTTP 主机必须在平台配置允许全局明文，该许可仅为必要平台开关，应用层仍默认拒绝；**全部其他客户端及跳转必须通过同一检查**。未证明全覆盖时先拒绝 HTTP 配置并记录未完成，不能带着绕过路径发布，也不扩成通用安全框架。[O-NSC]

关闭底层自动跟随跳转，由有界流程在每一跳连接前重新校验目标。相对 `url/pic/lrc` 或 `Location` 以实际最终响应地址解析为绝对 URI，`//其他主机` 同样重新检查。服务 Authorization/Cookie/用户配置的鉴权参数只发给精确 origin；新 origin 不转发、不重加，不共享网易云 CookieJar、Authenticator 或默认 headers。服务返回的资源签名按原 URL 保留，不能把 API 查询凭据额外拼到媒体/CDN；跨 host、port 或 scheme 的跳转均隔离鉴权。

## 3. 明确支持的初始协议形态

静态审阅的常见 MetingJS/APlayer 兼容形态为：歌曲详情返回包含 `name`、`artist`、`url` 及可选 `pic`/`lrc` 的数组，`url` 也可能是带签名参数并返回 HTTP 跳转的解析端点。这只是初始兼容配置，**并非所有名为 Meting 的服务都具有同样格式**。[M1][M2]

首版以该形态定义清晰的请求/响应适配及版本记录：

1. 当前网易云曲目映射为 `server=netease`、`type=song` 和原 ID。endpoint 模式用 URI builder 加入参数，保留其他参数但拒绝重复/冲突的保留参数；模板只替换查询值。未知来源不默认映射网易云，也不提前映射未来平台。
2. 验证状态码、大小、JSON/字段类型及结果数量。经典单元素数组没有回显 ID 时允许兼容，但标记“曲目匹配未验证”；有明确冲突 ID/来源则拒绝。多元素仅能在支持的协议字段中唯一精确匹配原来源/ID时选取，否则拒绝；不按曲名取第一项。空数组、错误对象或 HTML 不算成功，缺元数据沿用原曲目快照且不伪造质量/时长。
3. 使用响应里的音频 URL，保留服务返回的必要签名参数；不要求客户端获取自建服务的签名主密钥，也不从原曲目 ID 猜测 `url_id` 或重算签名。
4. `url` 及跳转执行2.1策略和第4节上限；不把音频流完整读入内存，不把 HTML/JSON 错误当音乐，不向 CDN 发送网易云或跨 origin 服务凭据。
5. 可读媒体须验证实际解码、seek、首声和结束行为。资源实际来源、质量、有效期或试听范围无法独立确认时记录未知/服务声明，不称“平台验证”；单元素兼容不是身份认证。不把“请求320”当实际码率，也不自动标记完整版、付费权限或 DRM 已解除。
6. 不兼容的用户服务给出可理解错误及修改/关闭入口，不偷偷换成项目指定的公共服务。其他封装以后按真实样本增加小适配，不增加可执行远程脚本。

本次不将 MetingJS/APlayer、Node.js、PHP 或整套服务端搬进手表；Android 端只需要与已选择协议兼容的 HTTP 适配器。

## 4. 性能、时序与结果语义

正常原生路径仍按14的健康Wi-Fi **4秒首声目标**验收，不增加Meting请求。下表为初始有界配置，性能口径在P0按14记录/冻结；DEV-224验证实际实现，不因此延后或静默放宽标准。尚无完整服务场景时保留初值，后续调整必须带证据。8秒是解析截止，**不是首声放宽到8秒**；媒体连接/缓冲到实际声音另报，不能用READY冒充。

| 边界 | 初始限制与执行方式 |
| --- | --- |
| 解析总预算 | 从本次原生资源解析开始以单调时钟计时，共8秒，包含原生＋Meting元数据请求、读取/解析及其中的跳转；原生失败不重置时钟，耗尽就停止 |
| 元数据 HTTP 请求 | connect timeout ≤ min(3秒, 剩余预算)，整个 call（包括读取）≤剩余预算；取消底层 call，不能只限连接而让读取无限挂起 |
| 元数据响应 | 解压后的 JSON 最多256 KiB，流式计数，超限立即关闭；不信任 Content-Length，不先无界读为字符串 |
| 跳转与重试 | 元数据解析整轮累计最多3次跳转；媒体/附属资源各自一次获取也最多3跳，实际请求仍遵守2.1。无隐藏自动重试；Meting补充一次，播放器资源刷新最多一次且共享当前操作剩余预算 |
| 资源缓存 | 仅当前操作/播放所需的短期资源；未知有效期不跨下一次播放操作复用，不永久存 URL，不预解析整队列 |

媒体HTTP初始连接超时5秒、连续无数据读取超时10秒，按14在P0记录并在DEV-224核对客户端确实生效；应用层初次缓冲/重缓冲连续15秒无可播放进展则停止等待并给显式重试。正常持续收到且可播放的音频不套8秒元数据call截止，也不按整首总时长超时。超时配置调整遵循14证据规则，失败仍受03的刷新/跳过上限约束。

仅服务已启用、原 TrackKey 可确定、预算尚余时，原生同 ID 的空 URL、明确试听或资源不可用允许尝试一次补充。**离线、用户取消、证书错误、429/限流、私有/账号内容需登录鉴权**直接停止该操作，按原因提示；不借备用服务反复撞授权，不反复请求无效 JSON/错误对象。Meting 空值、试听或不支持也如实反馈；未知完整性不能改成“完整版”，不能按名称自动找另一曲替换。

只在用户测试或当前曲目需要解析时调用；合并同曲目、账号和配置代次的重复请求，主线程不等待网络。资源提交在播放器所有者线程同时校验曲目、账号、queueGeneration、请求与配置代次；切歌/取消/配置变更的晚到回调不得抢播。配置更改停止未来旧配置请求但保留已打开的当前流，显式停止除外；它不等于再次请求旧地址的许可。

显示“通过自定义解析服务播放”及来源/匹配/质量的真实状态。封面/LRC缺失不延迟首声，本地链路不请求服务；仅进入本地页也不强停已有在线流。播放补充不推定价格、下载权或 DRM 能力，P4 仍须独立验证下载权限与完整性。

首版必须交付可配置的适配功能与其受控验证；不要求每位用户自建的未知实现都通过，也不把公共服务不可用当成本地音乐失败。有真实用户服务时可另附其验证结果；没有真实第三方服务实测时，明确仅验证初始协议和受控资源，不能宣布网易云曲库已全部“解锁”。

任务、依赖和验收以[05](05-开发阶段与任务清单.md)为准，不做工作量估算。本地LP-07的显式歌词/封面补全与Meting播放解析分开，用户开启补全不意味着允许向Meting发送本地文件或自动识曲；本地核心及未开启路径仍不请求Meting。
