# 在线必需列表与刷新失败

根据03的在线响应分类、DEV-204缓存刷新及FR-03契约，`LIKED.ids`和
`DAILY.data.dailySongs`必须是明确的JSON数组。HTTP或响应`code=200`不能
证明缺失字段代表零条曲目。缺失、null及错误类型返回原有`INVALID_RESPONSE`，
不发布成功空视图；明确的`[]`仍是正常空结果。其他可选列表字段的既有语义保持，
账号、分页、播放解析和Meting回退政策不变。

两个新增回归定义经过实际EAPI解析器及native Room刷新链路，分别覆盖喜欢和
日推的三种异常字段。异常后核对原快照、时间、持久行、当前缓存选择及已冻结
队列，确认本轮未发布视图已退休，缓存重读不增加接口调用。同一定义随后用
明确空数组验证正常空刷新，原队列租约继续保留其曲目。既有测试正文和期限保持。

输入是公开的合成响应，不包含实际账号或曲库；没有发起音乐服务请求。本地仅
核对文本、JSON夹具、调用点、原文与后像。Android编译、JVM回归、新云端验证、
设备及原AC均为NOT_RUN；全部128项本地需求及256个原AC的范围和门槛保持。
