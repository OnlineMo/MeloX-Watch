# LP-10 F-054 私有素材空间统计

本记录对应 [17 的 LP-10 契约](../17-本地音乐功能与实施计划.md#lp-10-文件写入与批量管理6项)和冻结的 [F-054 / AC-054-N、AC-054-E](../requirements/local-player-F001-F128.md#f-054-空间缓存与副本管理)。F-054 及两个原 AC 保持未验收；源码、云端检查、设备验收分别记录。

## 实现范围

存储页面在原件引用、音频副本、派生缓存、恢复暂存和剩余空间之外，分列已保存的歌词文档、确认封面、歌词字体、主题包和播放背景。各 owner 仅暴露私有目录的只读分类契约，统计不解析歌词、字体、图片、主题目录或备份 SQLite，也不执行资源恢复、配额淘汰或目录清理。统计结果不包含目录地址、素材身份或内容。

采用文件逻辑字节，不把配额每项预留字节算作已占用文件。清缓存仍调用封面与在线歌词的实际缓存 owner，保留音频、关联素材、收藏、歌单与恢复文件。音频导入和主题传输共享的 incoming 目录仅观察一次；LP-10 外部恢复文件与 LP-11 私有备份目录分别计入恢复暂存。

单个统计游标每次占用共享物理 IO 最多读取 100 个节点，批间让出调度。主题和背景沿用原文件锁，每批释放锁；目录身份、时间和有限 owner sentinel 检查跨批的移交与目录变化。变化范围不再显示可能重复的字节小计。可继续写入的 `.part`、`.partial`、主题暂存及设置暂存即使当次 stat 稳定，也明确显示为已知小计；未知项、读取失败和不可信父目录不会变成完整 0 B。

统计取消后先等待本次实际读取退出，再关闭游标和释放 LP-10 围栏。原生关闭失败保留最多一个游标，后续统计先关闭原游标再开启新文件，界面显示清理未完成；异常链保留关闭失败的原因。清缓存前后值也标明不完整计量，不用已知小计宣称精确释放量。文件计量不能替代写入配额、原文件删除证明或实际存储释放测量。

以下测试已写入源码，全部为 `NOT_RUN`，未赋予编译或运行信用。

| 测试文件 | 检查范围 |

| `StoragePrivateInventoryTest.kt`（7 项） | 实际字节与原件保留、健康父目录下缺目录、链接与未知文件、跨批暂存增长、incoming 移交去重、取消退出握手、关闭失败后重试原游标 |

集成夹具使用真实私有文件、Room 与已初始化备份 owner；字体、主题和背景设置中的受控原始字节用于核对统计不会启动格式解析或恢复。音频字节只验证保留，未验证解码、实际发声、播放时清理、设备文件系统或耗电。展示中的封面租约在真实磁盘缓存清理期间保持有效。
