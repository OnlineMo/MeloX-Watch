# LP-05 / F-060 CUE 持久身份与段读入

依据[17的LP-05契约](../17-本地音乐功能与实施计划.md)、[03共享模型](../03-技术架构与接口.md)和[固定F-060原需求与AC](../requirements/local-player-F001-F128.md#f-060-cue-分轨)，本说明落实完整CUE链路。139路径增量已准备并进入组合审查/接入；实现、真实schema8/云测试、设备播放和发布分别记录。两个原AC均未运行，纯解析、源码或静态审查不代表可播放支持。

## 身份、授权与整组发布

分段TrackKey与实体Location分开，持久身份包含来源、CUE文档、轨号、起止帧/时间及边界版本。接纳绑定同时保存CUE与音频的对象、授权/来源修订和内容证据；歌单、完整队列及恢复保留精确段引用，不靠曲名或当前页定位。正常重复扫描沿稳定身份更新版本，不复制分段；原整轨曲目与原文件保留。

CUE文本和每份引用音频都须分别在已授权范围内真实可读。v1处理UTF-8/BOM和明确GB18030重试，以及常见FILE、音频TRACK、TITLE/PERFORMER、INDEX 01；INDEX 00/PREGAP保存独立语义，每秒75帧换算保留精度。绝对路径或范围逃逸、坏编码、倒序/重叠、缺音频和取消均不能发布半组。整个候选组完成独立文档、音频与边界校验后，在短事务中切换完整组修订；失败保留既有关系和可解释状态，不把未见或解析失败当删除。

完整组核验查询完整原生/关联段域，不因100条库窗口或选中键域而裁剪。同组每份实际音频的授权、位置及内容围栏均重核；同名、旧URI字符串或M3U/JSON/备份提示不能恢复授权。外部导入只保存可移植逻辑提示，重新定位和预览确认后才接纳新的实际绑定。

## 段内时钟与物理所有权

段内播放、seek、结束和下一段使用同一真实媒体时间映射，实体起止在源帧/样本精度上核验；歌词时基同步转为段内时间，不用推算字时间或播放整轨冒充分段。完整持久队列仍跨全部分页，服务仅持有当前及相邻有界窗口，两个可选后端继续共用唯一会话及活动所有者。实际WAVE PCM段读入、首尾帧、seek与连续衔接须由后续云端和音频证据验证。

扫描和绑定校验与既有来源操作共用单物理IO占用及有界批次。取消只停止新工作并调度精确owner退休；提供方忽略取消或关闭失败时保留原占用，实际关闭完成后才允许下一次物理读取。失败按精确ticket保留原错和迟到退休回执，旧操作不能清新占用或覆盖新失败。播放器实际输入同样按其真实关闭结果退休，包装对象替换不提前释放句柄。

## 文件影响与待验收

多段共享原件，物理删除、标签写回、重命名/移动须列出全部受影响段和已证别名，并按[LP-10原件合同](LP-10-file-operations.md)独立确认与协调。移出逻辑条目不删除原件；物理标签不能覆写分段标题、艺人或段时长。缺失/撤权保留歌单位置、收藏和历史，可重新授权或关联，不自动联网补来源。

current8/future9及6→7→8迁移必须由真实Room导出和严格再导出准入。后续运行正常分轨起止/seek/下一轨，以及逃逸、倒序/重叠、缺音频、重复扫描、取消/关闭失败、重授、原件操作和恢复交叉回归。设备矩阵分别记录后端、格式、API/ABI、路由与圆/方窗口；全部原128项/256个AC及[14资源门槛](../14-性能优先与资源预算.md)保持，未实测组合不声明支持，readiness=false、candidate=null。
