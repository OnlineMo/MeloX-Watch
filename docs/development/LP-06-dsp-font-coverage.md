# DSP 页面字体覆盖增量

根据 LP-07、LP-12 与15的字体覆盖要求及 LP-06 的预设编辑契约，主题界面字体覆盖集补入
DSP 当前使用的 89 个静态 string 资源，包括 APE ReplayGain 来源。文字仍由当前
语言的 Android Resources 提供；不枚举运行时资源或读取整份曲库。

命名预设的选择、重命名、替换、删除与确认控件，以及当前名称输入框，通过布局
回调登记文字。`boundsInWindow()` 的祖先裁剪结果具有有限且正的宽高时才贡献
名称；滚出视口、切换设置分区或控件释放后移除对应文字。输入框保留原有编辑、
保存及取消行为。

页内登记受既有 32 个预设、每个预设 4 种显示角色和 1 个输入框的边界约束。
单项上限沿用 64 个 UTF-16 单位；超限时清空动态文字并传播既有
`INVALID_INPUT` 字体后备路径，不返回截断的可信覆盖集。隐藏长文字不参与
复制或覆盖检查。相同可见名称去重并采用稳定顺序，重复布局与角色变化保持
字体请求身份。

每个控件持有独立登记 token，替代控件后的迟到更新或关闭不会清除新登记。
关闭后的登记及页面不能重新附着。页面或窗口退休在现有两阶段字体释放的
第一阶段清除自己的文字；同页字体重绑保留当前文字，字体内存释放始终在
`finally` 执行。动态名称不持久化，不进入诊断、日志或云端材料。

回归定义包括 15 个页内所有权、可见输入、容量边界、分派及中英真实资源用例，
以及 2 个真实 WatchDspSettings Compose 视口、滚动、输入及分区退休用例。
Compose 裁剪定义只覆盖窗口内的矩形视口；圆屏边角、真实 IME 与设备上的
显示/输入效果需要独立验收。

本增量的 Android 编译、JVM 测试、云端验证与设备验收均为 `NOT_RUN`。
本地仅做文本、资源引用、调用点和补丁完整性检查；不据此完成原始 AC。
