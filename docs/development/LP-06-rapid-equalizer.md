# LP-06 连续调节的音频过渡

状态：源码及四项非零PCM回归定义；编译、云端测试、lint、APK、设备声音、性能及原AC全部 `NOT_RUN`。

当前均衡器按20ms在旧/新滤波输出间混合。若混合尚未结束就把“上一套滤波器”替换为当前新滤波器，再从零开始混合，第一帧会跳到未混合的完整输出。现在保留正在进行的过渡，只存最新待用设置，完成后从当前完整输出继续过渡。两套滤波器和一个待用设置均有界；快速预览、撤销及关闭不会形成第三套滤波器或无界请求队列。关闭前仍完成输出过渡，之后恢复原PCM字节直通；停用状态更新继续从实际处理器发布。

同格式且尾帧已消费完毕的完整流边界延续过渡与滤波历史；seek、格式改变和销毁清掉待用请求及旧历史。已经借给下游的输出缓冲在实际消费前仍占用，提前queueInput拒绝且不消耗新输入，避免复用同一ByteBuffer覆盖未消费PCM。既有EOS/压限尾帧修复保持独立。

四个定义验证1kHz非零信号的首个过渡与未被打断对照逐字节相同、之后达到最新增益曲线；快速取消最终恢复未经处理字节和正确停用状态；同格式完整边界保留未结束过渡；借出缓冲不被新输入覆盖。这些定义使用固定Media3 1.8.0与SDK26，未执行，不能替代F-057-E/F-077-E/F-123-E的设备波形、路由与实际无爆音验收。

没有新增依赖、播放器、音频输出或UI计时任务；来源与链路继续见[音效建设记录](LP-06-dsp.md)及[EOS缓冲所有权](LP-06-eos-buffer-ownership.md)。
