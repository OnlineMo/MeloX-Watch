# 来源入口与平台返回

根据 [LP-01 的 F-002、F-003、F-005～007 契约](../17-本地音乐功能与实施计划.md)，
来源页分别查询文件选择器、目录选择器和系统媒体提供方。组件可见、音频读取
权限和实际可读是独立状态；每次发起动作前重新查询。查询失败显示未知和
重新检查入口，不把未知当作组件缺失。没有选择器时仍可选择可读的媒体库；
当前入口不足时说明阻断条件，并保留返回、离线帮助和认证传输入口。

平台文件与权限请求共用一个槽。平台没有回传请求 nonce，因此失效的系统
选择必须先排空，才可发起下一次请求。合法返回只在内存中保留一份有界 URI，
页面恢复前不读提供方。预览不自动播放、索引、复制或持久化授权；保留授权
和加入库仍是独立动作。SavedState 仅保存槽版本、种类与随机 ID；新进程
所有者只恢复排空义务，不能恢复有效请求、URI 或权限。

真实 Library screen 转换立即退休导航所有者。Main 的同步 presentation 回调
同时核对外层页面，因此 Sources 到播放或设置再返回的同帧往返，也会退休
旧意图。平台 STOP 与真实导航分别处理：同一逻辑页的 STOP→START 可以
消费合法返回，主动离页、重新授权和新的外部意图会使旧返回失效。迟到的
结果和旧选择读取的错误不能覆盖新意图。来源重载和选择只等待自身实际准入的
读取退休，选择准入继续使用八秒累计等待与八次冲突上限。

新增十九个回归定义：八个真实 PackageManager/票据边界、九个真实提供方
与 SourcesVM 路径，以及两个 ComponentActivity/ActivityResultRegistry 返回
与重建定义。媒体替代使用可读的空媒体库，不能据此声明媒体解码或音频验收。
原二十一个 SourcesVM 定义的正文保留，选择夹具明确进入前台。

本地仅核对文本、调用点、资源和后像。Android 编译、JVM 回归、云端验证、
设备结果以及 AC-002/003/005/006/007-N/E 均为 NOT_RUN；全部 128 项和
256 个原 AC 的范围与验收门槛保持完整。
