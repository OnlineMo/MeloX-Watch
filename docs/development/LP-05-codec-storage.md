# LP-05 解码参数持久化

2026-11-22：本增量把自定义解码器已观测的参数保存到主库版本7的 `local_track_versions.codecParameters`。字段默认NULL，历史曲目仍保留身份、标签、统计、访问引用和用户关系；未知参数继续表示未知，不由文件后缀推断。

范围遵循[17本地契约](../17-本地音乐功能与实施计划.md)、[21全量需求](../21-本地播放器全量需求整合.md)及[解码来源记录](../upstream-migrations/LP-05-JMAC-DSD.md)。没有本地Android/JVM编译或测试，云端构建、设备音频、性能和原AC均未通过；没有在本地生成或修改7.json。

## 写入、查询和恢复

`LocalCodecParametersCodec`使用独立schema1的逻辑JSON，UTF-8最多2048字节，只接受已定义字段、有效字符串和精确整数。记录输入容器、编码、采样率、位深、声道，以及实际PCM输出采样率/位深；可选格式版本和压缩等级。重复字段、类型强制转换、较新schema和超限数据会报恢复错误，不静默删除参数。它复用已有纯JSON解析器，不创建网络客户端或读取来源。

扫描写入与曲目版本在同一Room事务完成。实际查询返回该版本的参数，因此旧冻结视图不会看到新版本数据。失败的元数据读取保留原参数；成功的新解析若没有自定义参数则写NULL，避免把旧解码参数套到变化后的文件。标签或移动协调沿用未改音频的版本参数，不能称为新的设备测量。

6→7迁移仅增加上述nullable TEXT列。LP-11组合时使用同一个有界逻辑编解码器，排除凭据、系统授权能力和不可移植路径；参数不授予原文件访问权，也不声明设备或后端已支持。
