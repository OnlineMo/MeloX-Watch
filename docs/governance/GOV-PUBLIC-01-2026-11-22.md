# 公开开发仓库与保护核验

2026-11-22，所有者明确授权隐私审查、整改后公开应用仓库，并立即保护main。按既有GOV-PUBLIC-01同时保护contribution和v*标签。实际可见性及规则已通过REST和GraphQL读回；普通PR及合并证据另列，不以文档CI代替应用构建。

隐私审查覆盖所有可达Git历史、远端分支和PR/Actions源对象、上传文件、Issue/PR历史编辑、日志和全部可下载产物。候选逐项分类，实际私值及未审公开对象均为0；原始材料、私值清单、个人路径和设备信息只留ignored本地。保留必要上游法律声明，不删除公共许可联系信息来伪造隐私通过。

两个分支要求PR、GitHub Actions App来源绑定的cloud-gate/pr-policy、strict、会话解决、管理员受约束，禁止强推与删除、无bypass。批准数0避免唯一所有者自我批准死锁，人工审阅和正常PR合并仍必须执行。v*禁止更新和删除，合法新标签创建路径保留。外部fork执行须审批，默认token只读且不能批准PR。

独立签名恢复隔离已另行只读核验，保持永久私有、Actions关闭及仅所有者访问。本记录不包含其标识、地址或秘密。

完整非敏感字段和审计/配置回执哈希见[机器记录](GOV-PUBLIC-01-2026-11-22.json)。普通PR验证当前为PENDING，获得实际运行和合并证据后更新。
