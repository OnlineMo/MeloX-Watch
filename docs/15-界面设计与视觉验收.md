# 界面设计与视觉验收

终审：2026-11-11；建设恢复：2026-11-15～16。共享播放与本地库页面正在实施，尚无可验收APK、真表截图或设备验收结果。颜色、字号、间距及过渡参数均为**初始设计值**，可据实际可读性和测量调整，不是不可修改的品牌标准。

## 1. 范围与优先级

**性能第一，界面美观第二，可读性必须达标。** 正确性、隐私、数据完整性和可访问操作为共同底线。性能标准与P0冻结记录唯一引用 [14](14-性能优先与资源预算.md)，交互结构见 [04](04-圆屏交互与适配.md)，代码审查见 [16](16-代码规范与可读性.md)。

产品面向无GMS硬依赖的普通Android智能手表，按运行时圆形或方形/矩形窗口适配。OPPO Watch X2只是当前可用的主测试设备，不是唯一支持型号；系统、输入法与辅助服务按能力核验，不能由型号/SKU或白名单推定。Wear OS专项整合另列后续阶段。首版包括完整本地音乐、网易云及用户可选的Meting，分别按 [17](17-本地音乐功能与实施计划.md)、[18](18-通用音源接口预留.md)、[19](19-Meting自定义解析服务.md)执行。未登录/断网不挡住本地入口。

本地范围以 [21 全量整合](21-本地播放器全量需求整合.md)、[128项/256AC矩阵](requirements/local-player-coverage.json) 和 [匿名原文](requirements/local-player-F001-F128.md) 为准，F-001–128全部必做，含原13项待定。原件删除/标签写回/移动、Wi-Fi与真实手机配套、双后端/DSP/额外解码、主题/字体/逐字/常亮均属于首个完整公开版本。运行时默认关闭和单设备受限不改变范围；内部开发只展示真实可用入口，未实现仍阻断完整版本验收。在线持久下载按P4另列。

黑底、薄荷强调、静态封面为起点，先让用户辨认歌曲、状态和主动作。每个当前任务只有一个最高强调动作，次级操作用中性行项或图标。P1即提供主按钮、列表行、状态提示和紧凑布局样例；P2补业务状态，P3完成真表验收，不把设计推迟到最后。

| surfacePressed | #263A30 | 固定几何的次级按下态 |
| textPrimary / textSecondary | #F2F7F4 / #B7C6BD | 主文与说明 |

项目采用所有有意义文字至少4.5:1、必要控件图形/边界至少3:1的设计尺度[R1–R3]；不声称整款应用已获WCAG认证。按实际相邻颜色及透明度合成结果计算，静态计算与真表可辨性分别记录。当前配色的主按钮使用onAccent，不能直接用浅色正文；改变颜色后重算相关组合即可。

| 正文 / 动作标签 | 16sp / 22sp |

默认使用系统字体/字形回退；F-115允许为歌词原文和译文分别选择合法TTF/OTF，F-116支持实际wght轴字重，资源边界见14。字体按sp、布局按dp；以实际字形检查换行和高度，不假定字体缩放线性[R4–R5]。中英文、长词、emoji/组合字符不能切断；摘要可省略，完整曲名可查看，错误和恢复步骤必须可完整读到。默认关闭跑马灯。

间距以4/8/12/16dp、圆边安全距8dp为起点。**独立触控目标至少48×48dp且无重叠**；主键56dp、行高56dp、图标24dp、封面48/64dp均为建议，空间允许时采用，文字放大时容器可增高。不能为守住建议尺寸损害核心功能或低于48dp底线。

- 主按钮显示真实播放/暂停/忙碌状态，按下可立即反馈已收到意图；不能把反馈当成音频成功。
- 列表行名称在先、艺人/数量在后；当前项有文字/图标，不能只靠颜色。返回保留位置。
- 封面和占位尺寸稳定，新曲缺图不沿用旧曲封面；同曲刷新失败可保留已有图。
- 提示紧邻相关内容，说明原因及一个主要恢复动作，不盖住主控制、不反复抢焦点。
- 提供名称、角色、选中/禁用/忙碌语义和合理焦点顺序；装饰不重复朗读，进度变化不频繁播报。

## 3. 形状适配与功能可达性

P0记录实际窗口px/density/dp、形状信息、偏移、系统/手势/输入法inset和字体档位。仅在`isRound`为真或经实测确认圆形时使用圆心/半径及下述圆形策略；不按型号猜测，不因IME缩窗重建假小圆[R5–R6]。

用户明确要求圆屏优先：先验证圆边的实际控件、首尾内容、长文和最大字体，再补方屏。已授权root测试虚拟机可临时调整分辨率/density以覆盖代表尺寸，原值和override保留在ignored本地并在每轮结束恢复；应用自身不修改系统显示参数。虚拟机系统当前报告矩形，需通过应用圆形布局选择并核对圆形可见区域作先期模拟；真实圆屏裁切、触控与系统遮挡仍在交付前真表验证。

方形/矩形窗口使用可用矩形和实际inset，保留可用边角，不无条件裁圆或套弦宽；未知形状先按系统窗口并核验真实可见区域。窗口尺寸、方向或inset变化时重新排布；共用控件、状态与功能保持一致。

**硬验收对象是实际控件热区、文字、焦点环与操作路径。** 它们须在当前可见可触区域内；列表可滚动，但首尾项和完整内容都须有可达的中央位置。不要求每一整行的外接矩形全部放进同一保守圆内。

仅圆屏的可选几何检查：对单个控件矩形，以圆心为原点、有效半径为 `r－安全距`，检查四角和系统遮挡交集；也可用该控件上下边离圆心的最远距离 `d` 求半弦宽 `sqrt(R²－d²)`。圆形热区可按其实际形状检查。这只是设计辅助，不能替代真表操作。

例如192dp圆屏、安全距8dp、居中的48/56/48dp三键加两处8dp间隔：整行168×56dp外框可能超出保守边界，但两侧48dp热区和中间56dp热区分别可以放下。**逐控件满足48dp、文字与手势避让时保留功能，不因整行外框失败强制移走上下曲。**

| 实际问题 | 优先处理 |
| --- | --- |
| 封面/长标题挤压主键 | 先缩减装饰或移除封面；保留曲名摘要、状态和播放控制，完整名称进详情 |
| 三键实际热区仍无法容纳 | 主键居中，次级控制进入明确可达的单列页；不缩小48dp目标 |
| 最大字体容不下一屏 | 增高行、滚动或分步布局；不强制降低系统字体，不让主键与文字重叠 |
| 圆边列表行/长歌词不完整 | 首尾留白、滚到中央、长内容详情；边缘预览不能是唯一操作位置 |
| IME/二维码占用空间 | 独立输入或扫码步骤；说明/刷新可到相邻步骤，返回可达 |
| 编辑/重排/删除动作拥挤 | 单任务操作页，显示对象和后果，保留取消；不用微小行尾图标作为唯一入口 |

系统返回手势保留，横向分页从内容区开始；表冠默认在列表滚动，F-082显式启用后可在播放页映射进度或系统媒体音量并选方向，F-083独立触觉启停。全部任务保留触控路径。公式、模拟图和建议尺寸都不能推翻真实设备的功能可用性要求。

二维码与四模块静区完整显示[R8]，不压图、不裁边；说明或刷新可分步，真表实际扫码成功才通过。扫码失败不能用一张清晰设计图抵消。

| 搜索/排序 | 搜索索引中的曲名/艺人/专辑/文件名，部分索引明确范围；排序字段/方向可见、相同键顺序稳定，不改活动队列 |

| --- | --- |

## 6. 状态与可访问性

简体中文和英文必须覆盖全部关键操作、加载、空态、错误、部分结果、禁用原因、帮助及许可说明；内容标签保留原文，不翻译用户元数据。语言切换和重建保留草稿且不重放动作。初次完整验收覆盖所有适用状态；共用组件的通用状态可集中证明，各页面业务特有分支单独验证。后续PR只复核受影响页面/状态和共用组件的影响范围。

| 状态 | 通过条件 |
| --- | --- |
| 默认/按下/焦点/选中 | 层级清楚、几何稳定；颜色以外有文字/符号，焦点环完整 |
| 解析/缓冲/加载 | 静态状态词和可执行的取消/返回，目标歌曲或已有内容保持，不伪造播放成功 |
| 禁用/空 | 原因可读、语义正确；区分真实无数据、未扫描、未登录、无查询，下一步实际可执行 |
| 缓存刷新/追加失败 | 保留内容和位置，重试范围正确，只有成功才更新新鲜度 |
| 可恢复/权限/账号错误 | 保留允许保留的上下文，给对应恢复动作；不展示旧账号私密数据、原始响应或凭据 |
| 本地部分完成/编辑失败 | 区分已提交数据与草稿，取消/恢复可达；不误报完成，不清空原库 |
| 返回/重新可见/重建 | 从当前会话/数据恢复状态和位置，不重播历史事件或动画 |

实际手指操作、辅助焦点、系统返回、IME和扫码分别验证；该固件没有的辅助服务记录受限，仍检查应用语义与触控可用性。不以低透明度、颜色、声音或触觉作为唯一反馈。

## 7. 动效与生命周期

默认静态更新。确需交代空间变化时可用一次短淡入/小位移，120ms、最长180ms、8dp为初始设计参考，服从14的响应与资源标准；连续输入取消过时过渡，不排队播放动画。

默认无常驻旋转封面、呼吸、音谱、粒子、循环shimmer或跑马灯。F-099必须提供默认、纯黑、静态封面模糊、静态流体配色、自定义图五种背景；模糊在图指纹/尺寸/强度变化时离屏计算并缓存，不逐帧重解码，流体为静态生成。F-100模糊强度只作用适用模式，遮罩增大更暗且保持对比度；快速预览合并过时任务。手势直接响应，业务不等动画。

尊重设备可用的减少/关闭动画设置[R7]；无对应系统入口时记录限制并验证静态模式。关闭动效后文字、状态和功能仍完整，不能依赖GMS辅助服务。

页面不可见（含相邻隐藏分页）或熄屏时停止UI计时、动画、歌词跟随与进度插值。重新可见读取当前快照，不补播隐藏tick。F-103常亮默认关闭，显式开启后仅当前可见歌词页持有，离页/后台/锁屏/播放结束/销毁/异常退出解除；不能靠常亮保后台音频。F-110只有真实字时间才强调，行级输入保持逐行，不伪造字时间；减少动效仍可用静态当前字与完整文本。F-084显式外部歌词会话由独立有界所有者处理，不能绑隐藏UI轮询或被停UI误关。黑屏录像不能证明无后台工作，需诊断证据。
