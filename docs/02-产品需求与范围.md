# 产品需求与范围

状态：仅规划，功能尚未实现、验收尚未执行。用户已确认本地 F-001～F-128 全部必做；参数候选、设备待测与范围是否纳入分别记录。

## 1. 定位与设备边界

面向普通 Android 智能手表提供可独立使用的在线＋本地音乐播放器：抬腕选歌，连接耳机后听网易云音乐或手表已有音频文件，熄屏保持播放；后续 P4 再增加在线下载。主流程不依赖 GMS 或手机伴侣，产品不限定 OPPO 或某个型号。

用户现有 OPPO Watch X2 是当前主要实机验收设备，不能据此设机型白名单或推定其他手表已测。布局按实际窗口大小、圆/方屏形状、inset、字体与输入能力适配；首版共用组件提供方屏基础布局，不另建 Wear OS 技术栈。兼容范围按 API/ABI、权限、音频和输入/文件能力及已测固件说明。

首个完整公开版本（沿用 `0.1.0` prerelease 规划）必须交付既定在线功能、完整本地 **128 项**及用户自填 Meting P2-M。内部按05分批集成，不能用旧 P2-L/MVP 的较小范围通过公开门槛。逐项契约在[匿名需求基线](requirements/local-player-F001-F128.md)，范围覆盖及256个原始AC映射在[21 全量整合](21-本地播放器全量需求整合.md)，本地设计在[17](17-本地音乐功能与实施计划.md)，Meting仍按[19](19-Meting自定义解析服务.md)。本轮仅更新规划，不启动 Android 实施。

原稿中 F-051、F-056、F-058、F-059、F-060、F-061、F-062、F-063、F-068、F-069、F-070、F-071、F-075 的“范围待明确”“候选契约”“纳入后”属于历史措辞，现均为必需功能。运行时可选只表示用户可不开启；开发、正常与异常验收不能省略。未登录、账号过期、无网络或未安装伴侣时，本地接入、浏览、管理和播放仍独立可用。

实际 SKU、系统 API、厂商应用限制、蓝牙音频路由、Wi-Fi/eSIM 网络与表冠事件仍待验证。不会根据同名产品的其他地区版本推断这台设备具有 Wear OS 能力。Wear OS 属于扩展验收对象。

## 2. 典型任务

| 场景 | 用户路径 | 结果 |
| --- | --- | --- |
| 首次本地使用 | 打开应用 → 本地音乐 → 授权实际可用来源 → 扫描 → 点歌 | 无账号、无网络也能浏览和播放 |
| 初次在线使用 | 打开应用 → 在线音乐 → 查看二维码 → 手机网易云扫码确认 → 返回手表 | 手表独立持有经校验的会话 |
| 快速在线听歌 | 打开应用 → 在线我喜欢/歌单/日推 → 点歌 | 在手表输出音频，展示明确的播放状态 |
| 整理本地库 | 本地音乐 → 歌曲/专辑/艺人/文件夹或授权来源 → 搜索/排序 → 本地收藏或播放列表 | 管理本地列表及顺序；来源不暴露父目录时不伪造文件夹 |
| 散步时控制 | 抬腕 → 暂停/切歌 → 放下手腕 | UI 休眠，音频服务继续播放 |
| 查看歌词 | 播放页向左切到歌词 → 查看当前行 | 歌词跟随进度，可返回当前行 |
| 首版本地外出 | 已索引手表文件 → 关闭所有网络 → 本地列表播放 | 不请求音频、封面、歌词或账号接口 |
| P4 下载外出 | Wi-Fi 下下载 → 断网 → 下载列表播放 | 单独的持久下载库，不与用户本地文件混为一类 |
| 恢复使用 | 应用被系统回收 → 再次打开 | 恢复队列与位置，等待用户确认后播放 |

网易云二维码登录只需要用户用任意可用方式完成扫码确认，不把 LP-14 配套端作为登录前置；音乐服务本身的账号与歌曲权限仍以服务端响应为准。LP-14 的真实 Android 手机配套仍是首个完整公开版本的独立必做交付，用于传歌、主题、曲库、歌单和信息管理。登录链路能否在实机完成属于 P0/P2 的验证项。

在线“我喜欢”和在线歌单首发只读，在线收藏写入与歌单编辑不在范围内；本地收藏、歌单和文件管理依21完整实现，命名与存储和在线分开。评论、私信、播客、云盘上传、在线识曲、AutoMix双播放器交叉淡化、PCM网络投放和插件音源仍不列入首发验收；本地EQ、压限器及DSD转PCM属于已确认范围。

本地范围是手表上的用户音频文件：MediaStore、单文件URI、授权目录及用户明确导入/传入的副本是分别验证的来源选项，不要求一台设备同时具备所有入口。先核验实际API、选择器、读/写/删能力与离线可读性，不用root、全盘权限或私有路径补洞。复制需明确告知空间及卸载影响，不能自动复制整库。基础格式、CUE、APE与DSF/DFF按容器、编码、参数、ABI、后端和输出路由建立支持矩阵；额外解码器需许可与实机验证，不提前选版本，不处理DRM私有加密音频。

**F-053原文件物理删除必须提供，与移出来源/索引、移除歌单成员和删除应用副本分别命名。** 用户确认对象和后果，再按实际MediaStore/SAF支持及系统确认执行；取消保留未执行对象，批量逐项记录，失败不假报删除，不承诺通用回收站。扫描、清缓存、退出账号和删除列表仍绝不自动删除音频。F-063必须真正写回支持格式的标签；F-075需保持逻辑身份、先校验目标再处理源，跨provider无通用原子事务保证，详见03/17。

搜索、命名、标签及Meting配置依赖真实输入路径；无输入法须记录阻断或验证明确设计的合法替代，不能用演示文字验收。必需手机配套端不自动成为手表输入前置。单个音频URI不授予同目录LRC、CUE、字体或主题权限；每类资源分别授权。特定设备显示“不支持”只覆盖异常路径，项目完成仍需在声明支持的组合完成正常AC。

## 5. 产品默认值（待实测调优）

- 在线音源：网易云；默认标准音质，允许高品质；更高音质暂不作为首发要求。本地文件按其实际编码播放，不套用在线音质或账号权益判断。
- Meting：用户填写自己的服务地址后主动启用；不内置公共地址、不承诺全部“解锁”，实际来源/未知音质/试听/失败如实反馈。服务配置不等于新音乐平台账号，曲目身份仍保留原来源，见 [19](19-Meting自定义解析服务.md)。
- 下载：默认 Wi-Fi、并发 1；若播放正在缓冲，优先播放并暂停新下载。
- 缓存：建议初始流媒体缓存 128 MiB；持久下载上限建议 1 GiB，并且总是保留至少 512 MiB 可用空间。P0/P4 按实机剩余空间调整，不能按标称容量硬编码。
- 动效：纯黑背景，封面静态，歌词逐行；不默认模糊/发光/实时玻璃背景。
- 输出：遵循系统当前音频路由；蓝牙耳机断开暂停；外放需用户明确恢复。
- 恢复：恢复可见状态，不因开机、充电或网络恢复自动开始播放。
- 队列：完整逻辑队列保存在数据库，移除旧10000条用户范围上限；当前视图完整分页范围均须纳入。内存、事务批次及媒体后端窗口仍有界，失败或取消回到旧完整队列，不截断后宣告成功；语义以03为准。
- 本地扫描全局并发初始1、分批写Room；不启动全扫/预提全库封面歌词。封面/歌词初值和P0冻结统一见 [14](14-性能优先与资源预算.md)。需要导入副本时初始独立上限1GiB，且不得用尽512MiB可用空间预留；每批按实际剩余空间扣除全部应用占用，未知大小逐步检查。P0按设备校准后冻结，后续变更需证据，不留无限配额待以后再定。

首版同时执行 [14 性能预算](14-性能优先与资源预算.md)、[15 视觉验收](15-界面设计与视觉验收.md) 和 [16 代码规范](16-代码规范与可读性.md)。在线熄屏至少60分钟、本地熄屏至少120分钟及全部新增能力的适用证据均是公开门槛。资源初值需要覆盖DSP、扩展解码、主题和完整队列；若有冲突，提出证据与配置/实现决策，不能自动删需求、虚报支持或沿用不适用的旧基线。本计划不提供人日、工期或代码量估算。

## 6. 独立模式和协同模式

独立模式是主产品路径：在线时手表直接请求元数据及音频，手机离线不影响手表已完成登录后的常规操作；本地模式直接使用已授权文件，从启动到播放、收藏和列表管理都不依赖账号或任何网络。是否能联网取决于设备网络能力与当前连接，不把“手机蓝牙已连接”当成手表有互联网。

“本地零网络”指冷启动、授权扫描、浏览/整理及本地播放本身不发起应用HTTP、DNS、账号、遥测或自动补图/歌词请求。F-070/F-071默认关闭，即使启用仍须每次明确请求、说明最少发送字段并预览确认；失败或关闭取消其任务，不能覆盖本地资料。F-066/F-067配对传输、F-084兼容歌词输出、F-118更新、F-120外部支持是独立显式用户意图，具有各自权限、取消与隐私边界；不能借此给本地入口预热网络或上传整库。进入本地页不强停已发起的在线流，混合队列的仅本地意图仍不自动联网。

手机配套是必须实现、用户按需使用的独立Android客户端，未来同仓库模块为`android/:companion`；分发/认证协议由LP-13/14在实施前形成决策及双端验证，不以网页上传替代F-067/F-097/F-124～F-126。其它手机平台尚未承诺，不影响Android客户端交付。手表来源、权限、队列与本地账号隔离保持独立，撤配对后对端不能继续查询或写入。

后续 LAN 模式显示明确的“控制手机”或“在手表播放”目标。控制手机时不得意外启动手表音频；队列移交只传曲目身份和进度，由接收端重新解析音源。安全账号同步需要单独设计及手机端改造，不列为现有 LAN 协议能力。
