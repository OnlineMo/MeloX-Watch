# 产品需求与范围

状态：规划稿。下列功能、阈值和优先级是拟议目标，均未实现。

## 1. 定位与设备边界

面向普通 Android 智能手表提供可独立使用的在线＋本地音乐播放器：抬腕选歌，连接耳机后听网易云音乐或手表已有音频文件，熄屏保持播放；后续 P4 再增加在线下载。主流程不依赖 GMS 或手机伴侣，产品不限定 OPPO 或某个型号。

用户现有 OPPO Watch X2 是当前主要实机验收设备，不能据此设机型白名单或推定其他手表已测。布局按实际窗口大小、圆/方屏形状、inset、字体与输入能力适配；首版共用组件提供方屏基础布局，不另建 Wear OS 技术栈。兼容范围按 API/ABI、权限、音频和输入/文件能力及已测固件说明。

首个公开 `0.1.0` prerelease 必须交付在线、本地 P2-L 和用户自填 Meting P2-M，均属 P0–P3 的必需范围。未登录、账号过期、完全无网络时仍能进入本地库、管理本地播放列表并播放已授权文件；不把扫码或网络检查作为应用首页和本地菜单的进入条件。具体方案见 [17-本地音乐功能与实施计划](17-本地音乐功能与实施计划.md) 和 [19-Meting自定义解析服务](19-Meting自定义解析服务.md)。本轮仅更新规划，未授权启动 Android 实施。

实际 SKU、系统 API、厂商应用限制、蓝牙音频路由、Wi-Fi/eSIM 网络与表冠事件仍待验证。不会根据同名产品的其他地区版本推断这台设备具有 Wear OS 能力。Wear OS 属于扩展验收对象。

## 2. 典型任务

| 场景 | 用户路径 | 结果 |
| --- | --- | --- |
| 首次本地使用 | 打开应用 → 本地音乐 → 授权实际可用来源 → 扫描 → 点歌 | 无账号、无网络也能浏览和播放 |
| 初次在线使用 | 打开应用 → 在线音乐 → 查看二维码 → 手机网易云扫码确认 → 返回手表 | 手表独立持有经校验的会话 |
| 快速在线听歌 | 打开应用 → 在线我喜欢/歌单/日推 → 点歌 | 在手表输出音频，展示明确的播放状态 |
| 整理本地库 | 本地音乐 → 歌曲/专辑/艺人/文件夹或授权来源 → 搜索/排序 → 本地收藏或播放列表 | 管理本地列表及顺序；来源不暴露父目录时不伪造文件夹 |
| 散步时控制 | 抬腕 → 暂停/切歌 → 放下手腕 | UI 休眠，音频服务继续播放 |
| 查看歌词 | 播放页向左切到歌词 → 查看当前行 | 歌词跟随进度，可返回当前行 |
| 首版本地外出 | 已索引手表文件 → 关闭所有网络 → 本地列表播放 | 不请求音频、封面、歌词或账号接口 |
| P4 下载外出 | Wi-Fi 下下载 → 断网 → 下载列表播放 | 单独的持久下载库，不与用户本地文件混为一类 |
| 恢复使用 | 应用被系统回收 → 再次打开 | 恢复队列与位置，等待用户确认后播放 |

手机仅承担二维码扫码确认时，不需要安装 MeloX 手机伴侣；音乐服务本身的账号与歌曲权限仍以服务端响应为准。登录链路能否在实机完成属于 P0/P2 的验证项。

## 3. 版本范围

| --- | --- | --- | --- |
| 普通 Android 手表安装、圆/方屏布局、无 GMS 启动 | 必须；当前以 Watch X2 主测，方屏基础布局另验 | 回归 | 扩展设备实测覆盖 |
| 独立扫码、退出、过期重登 | 必须，前期验证可行性 | 稳定化 | 手机辅助账号迁移 |
| 我喜欢、用户歌单、每日推荐 | 必须 | 分页与缓存收敛 | 更多推荐入口 |
| 搜索歌曲 | 经 P0 验证的系统文本输入、历史/清空、真实分页；无输入能力则阻断该需求验收 | 可用性优化 | 新输入方式单独评估 |
| 在线播放和队列 | 必须 | 稳定化 | 更多音源 |
| 用户配置 Meting 解析 | 初始协议适配、地址/模板、测试/启停与有界失败处理；默认关闭、用户可自建 | 回归 | 新服务协议按真实需求评估 |
| 本地文件访问、扫描与增量索引 | 必须；MediaStore / SAF 以实机可用路径为准 | 大库与升级回归 | 其他来源另评估 |
| 本地分类、搜索、排序 | 歌曲、专辑、艺人、可证实的文件夹；父目录不可见时按授权来源分组；分批查询 | 稳定化 | 更多筛选 |
| 本地播放列表与收藏 | 新建/查看/重命名/删除、成员增删与重排、收藏/取消 | 异常恢复增强 | 独立备份/同步另评估 |
| 本地封面与 LRC | 按需读取已授权资源；无图/无歌词不阻断播放 | 回归 | 其他歌词格式另评估 |
| 熄屏播放、系统媒体控制、耳机按键 | 必须 | 长时间回归 | 厂商增强 |
| 逐行歌词 | 必须 | 离线保存 | YRC/TTML 逐字和翻译开关 |
| 在线持久下载、暂停/继续、下载库 | P4 能力，首版可暂缺；本地播放器仍是首版门槛 | 必须 | 批量同步与高级下载策略 |
| 本地播放历史、队列恢复 | 必须 | 异常恢复增强 | 跨端队列移交 |
| 设置 | 账号、音质、缓存、本地来源/授权/扫描、诊断基础项 | 下载与存储管理 | 睡眠定时、更多个性化 |
| LAN 手机遥控 | 预留接口 | 不阻塞 1.0 | 可选独立阶段 |
| Wear OS 专属集成 | 保持核心可移植，不作为普通 Android 手表路径的前置 | 不阻塞主产品发布 | 专门构建与设备验收 |

在线“我喜欢”和在线歌单首发只读，在线收藏写入与歌单编辑不在范围内；**本地收藏和本地播放列表完整 CRUD、成员重排属于首发必需能力**，两者命名与存储分开。评论、私信、播客、云盘上传、在线识曲、均衡器、AutoMix、PCM 投放和插件音源不列入首发验收。

本地范围是手表上的用户音频文件：优先引用 MediaStore 或系统文件/目录选择器授权的 URI，SAF 仅在实际固件支持时启用。需要应用持有副本时才显式提供导入，先告知空间成本并检查配额/剩余空间；不自动复制整库。无合法可用访问路径是 P0 阻断，不能用 root、全盘访问权限或私有路径绕过。首发不内置 Wi-Fi 传歌、标签编辑、CUE、额外解码器或 DRM 解密。MP3、AAC/M4A、FLAC、WAV、Ogg/Opus 只是候选测试格式，按实际容器＋编码＋固件验证，不承诺所有扩展名都能播放。

首发不提供外部原文件物理删除 UI；移除来源/索引、取消收藏和删除播放列表都保留原文件。仅应用持有的显式导入副本可单独确认删除，外部原件仍保留。

搜索、列表命名及 Meting 地址/测试 ID 输入都依赖07的真实输入探针；系统输入法不可用时记录阻断，不能用固定演示文字验收，也不自动新增自制键盘或手机伴侣。单个音频 URI 不授予同目录 LRC 权限；有可用文件选择器时允许明确选择歌词，否则显示未授权/无法添加，不承诺自动发现。

## 4. 可验收需求

| 编号 | 需求 | 验收要点 |
| --- | --- | --- |
| FR-01 | 普通 Android 手表安装和启动 | 在满足声明能力的设备正常安装/启动，无 GMS 不崩溃；当前以 Watch X2 留实机证据；无 root/机型白名单，未测设备不冒称已通过 |
| FR-02 | 登录生命周期 | 明确等待扫码/确认/过期/网络失败；离开页停止轮询；成功后验证账号；重启仍有效或明确提示需重登 |
| FR-03 | 在线音乐库读取 | 在线喜欢、歌单、日推有加载/空/错误/过期状态；大歌单按批加载；不重复请求已加载页 |
| FR-04 | 在线搜索 | 支持输入和取消；新查询取消旧任务；分页去重；“没有更多”必须来自可验证分页结果 |
| FR-05 | 播放 | 播放/暂停/上一首/下一首/跳转；顺序、随机、列表/单曲循环；队列冻结、首尾和失败上限按03第6.1节，显示加载、缓冲、不可播放 |
| FR-06 | 后台和路由 | 退后台、熄屏继续；来电/抢占按焦点策略暂停或降低音量；耳机断开默认暂停，避免自动扬声器外放 |
| FR-07 | 恢复 | 保存队列引用、冻结顺序、实际随机顺序、当前条目/索引、模式、位置；进程结束后恢复不重洗牌；强制停止或重启后不自动发声 |
| FR-08 | 歌词 | 逐行跟随，支持无歌词/纯音乐；切歌后旧歌词不覆盖新歌；手动浏览可回到当前行 |
| FR-09 | P4 在线下载 | 显式用户触发，默认 Wi-Fi；显示等待/运行/暂停/失败/完成；中断重启后恢复状态；不把临时播放缓存当下载完成 |
| FR-10 | P4 下载库离线播放 | 关闭网络后播放已完成下载；封面/歌词已缓存时显示；缺失文件显示修复/重新下载，不静默联网 |
| FR-11 | 存储管理 | 区分用户外部文件、应用导入副本、P4 持久下载和临时缓存；清缓存/退出账号不删本地库或音频；删除副本/下载明确范围，低空间暂停新复制/下载 |
| FR-12 | 可诊断 | 可查看版本、系统与脱敏错误码；诊断不含 Cookie、二维码 key、签名音频 URL；导出由用户显式操作 |
| FR-13 | 本地访问与索引 | 首扫/增量扫可取消；Room 分批事务；权限拒绝/撤销保留旧索引并给稳定错误；失败或取消不能删除未扫描项 |
| FR-14 | 本地浏览与检索 | 歌曲/专辑/艺人/文件夹或授权来源、本地收藏/播放列表可达；搜索曲名/艺人/专辑/文件名，排序稳定；至少 1000 首真实分页，不全量 JSON 读写 |
| FR-15 | 本地播放列表与收藏 | 完整 CRUD、成员增删/重排、收藏切换持久化；删除列表或成员不删除文件；不受在线退出或切账号影响 |
| FR-16 | 本地共享播放与恢复 | URI 进入同一播放器；本地冷启动/操作/播放不依赖账号，不发起应用网络请求（边界见第6节）；本地封面/LRC 按需读取；缺失/移位/权限失效保留身份并可恢复；首版实机本地熄屏至少 120 分钟 |
| FR-17 | 自定义 Meting 解析服务 | 用户自填/自建地址，默认关闭无公共默认值；测试兼容协议及实际资源；正常路径不额外请求，失败补充解析有界可取消；配置切换无旧回调抢播，不外传网易云 Cookie，本地零请求；范围见 19 |

## 5. 产品默认值（待实测调优）

- 在线音源：网易云；默认标准音质，允许高品质；更高音质暂不作为首发要求。本地文件按其实际编码播放，不套用在线音质或账号权益判断。
- Meting：用户填写自己的服务地址后主动启用；不内置公共地址、不承诺全部“解锁”，实际来源/未知音质/试听/失败如实反馈。服务配置不等于新音乐平台账号，曲目身份仍保留原来源，见 [19](19-Meting自定义解析服务.md)。
- 下载：默认 Wi-Fi、并发 1；若播放正在缓冲，优先播放并暂停新下载。
- 缓存：建议初始流媒体缓存 128 MiB；持久下载上限建议 1 GiB，并且总是保留至少 512 MiB 可用空间。P0/P4 按实机剩余空间调整，不能按标称容量硬编码。
- 动效：纯黑背景，封面静态，歌词逐行；不默认模糊/发光/实时玻璃背景。
- 输出：遵循系统当前音频路由；蓝牙耳机断开暂停；外放需用户明确恢复。
- 恢复：恢复可见状态，不因开机、充电或网络恢复自动开始播放。
- 队列：初始活动队列上限10000条引用，超限明确选择仅播所选曲/缩小选择/取消；不静默截断。列表修改不改已冻结队列，资源按需解析；语义以03为准。
- 本地扫描全局并发初始1、分批写Room；不启动全扫/预提全库封面歌词。封面/歌词初值和P0冻结统一见 [14](14-性能优先与资源预算.md)。需要导入副本时初始独立上限1GiB，且不得用尽512MiB可用空间预留；每批按实际剩余空间扣除全部应用占用，未知大小逐步检查。P0按设备校准后冻结，后续变更需证据，不留无限配额待以后再定。

首版同时执行 [14 性能预算](14-性能优先与资源预算.md)、[15 视觉验收](15-界面设计与视觉验收.md) 和 [16 代码规范](16-代码规范与可读性.md)。在线熄屏至少 60 分钟与本地熄屏至少 120 分钟均为 `0.1.0` 门槛，不推迟到 P5。

## 6. 独立模式和协同模式

独立模式是主产品路径：在线时手表直接请求元数据及音频，手机离线不影响手表已完成登录后的常规操作；本地模式直接使用已授权文件，从启动到播放、收藏和列表管理都不依赖账号或任何网络。是否能联网取决于设备网络能力与当前连接，不把“手机蓝牙已连接”当成手表有互联网。

“本地零网络”指冷启动进入本地及本地操作链路不发起应用侧 HTTP、DNS、账号、遥测或补图/歌词请求；不把系统自身流量算成应用请求。进入本地页面不强停用户已经发起的在线播放，也不改变既有混合队列策略；仅本地播放意图遇在线项按03有界跳过并提示，不能自动联网。

后续 LAN 模式显示明确的“控制手机”或“在手表播放”目标。控制手机时不得意外启动手表音频；队列移交只传曲目身份和进度，由接收端重新解析音源。安全账号同步需要单独设计及手机端改造，不列为现有 LAN 协议能力。

## 7. 范围变更规则

按 [18 通用音源接口](18-通用音源接口预留.md) 从当前网易云/本地需求中抽取必要的来源身份、数据访问和播放解析接口，方便以后扩展。不指定未来平台，不预设登录方式、能力集合或接入范围；真正接入时再依据需求评估，不提前创建平台模块或展示假入口。

P0 按09/20先完成 DEV-004-A 云端最小探针，再进行 DEV-002/003/005，DEV-004-B 记录实机基线；P1 扩充同一工程。设备、输入、登录及本地访问结论决定 `minSdk`、布局和依赖冻结。无法安装、稳定后台播放、完成必需输入或访问本地文件时，记录对应阻断并调整计划，不能跳过首版门槛。任务与工期仅以05为准。

新增音源、手机伴侣、逐字特效或 Wear OS 专属入口应建立独立任务与估算，不挤占在线＋本地 MVP 的后台播放和手表布局验收时间。
